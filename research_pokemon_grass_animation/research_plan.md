# Research question

Find open-source or permissively licensed resources that can support a clean, code-integrated 3D creature animation in the existing Three.js contribution-graph grass: hover grass, reveal a startled creature, animate a brief movement, then hide it.

## Subtopics

1. Open-source 3D creature/model resources: find usable low-poly creature assets and verify licenses, attribution, and redistribution constraints.
2. Browser 3D animation pipelines: compare glTF/GLB animation resources and Three.js-compatible loaders/animation techniques for a performant integration.
3. Interaction and implementation references: find examples or libraries for hover-triggered reveal, state-machine timing, and hiding/releasing the creature inside a grass scene.

## Synthesis

Recommend one safest asset path and one implementation path for this repository, with explicit licensing risks, runtime cost, and a concrete integration shape. Prefer original or generic creature assets over copyrighted Pokémon models unless the user accepts takedown/redistribution risk.
