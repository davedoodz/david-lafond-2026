1. 01Material record readyOnce all information is added, the provider reviews the material record and clicks “Share” to generate a unique URL.
  2. 02Generate a unique material URLThe provider creates a shareable link with custom permissions and tracking options.
  3. 03Attach the URL to an NFC tagThe provider taps an NFC tag to write the material URL. The tag is now linked to the same digital record.
  4. 04Tag successfully linkedThe NFC tag is now programmed with the material URL and can be attached to the physical swatch.
  5. 05Share via emailThe provider shares the material URL with relevant contacts, with an optional message and summary card.
